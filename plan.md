# Questions
## How well can the level of corruption of a country in Europe be quantified?

Maybe compare the data quality and availability to measure corruption for countries in Europe vs countries outside? Need to set up a baseline for what exactly *is* corruption.

## What characteristics of a country predict the level of corruption?

First step, set a value or metric to measure corruption. Then create a model to predict this value based on other data. Ideally, the model should be able to do some sort of feature selection. If all goes well, Bob's your uncle.

## What characteristics of a country predict an increase or decrease in the level of corruption?

Same as above, but with a time series, or at least comparing differences between predictors in two different years?
